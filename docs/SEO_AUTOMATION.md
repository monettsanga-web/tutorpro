# TutorPro SEO Automation

Run:

```bash
npm run seo:automation
```

The script generates:

- `seo-output/seo-report.md`
- `seo-output/seo-report.json`
- AI-assisted draft articles in `seo-output/drafts/`

## What it does

- Suggests article ideas
- Generates first draft outlines/articles
- Recommends internal links
- Creates a keyword-ranking tracking template
- Identifies content gaps from existing source/public pages

## Important

Always review AI-generated content before publishing. Verify all claims, prices, links, competitor comparisons, and calls to action.

## Ranking monitoring

The current version creates a ranking-monitor template. To automate live rankings later, connect Google Search Console API credentials or an SEO provider API.
